# JumpTurn Demo

A four-room precision platformer vertical slice with 90-degree world rotation and positive/negative phase switching.

## Controls

- Move: A/D, arrow keys, or left stick
- Jump: Space or gamepad south button
- Rotate stage: Q/E or gamepad shoulders
- Toggle phase: Left Shift or gamepad west button
- Pause: Escape or gamepad start
- Restart: R or gamepad select

## Run

Open `Assets/JumpTurn/Scenes/JumpTurnDemo.unity` and press Play. The scene is also first in Build Settings for Windows x64 builds.
