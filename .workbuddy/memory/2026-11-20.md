## 素材盘点（JumpTurn 精准跳跃 Demo）

工程现状（盘点结论）：
- 美术仅 3 张 Kenney 1-bit PNG：Character 96x16（6 帧）、Ghost 48x16（3 帧）、Tilemap 320x320；只切出 grassTop(240,128) + dirtFill(160,128) 两块瓦片。
- 敌/危险物混用：Patrol 与 Bird 都取 Ghost.png；Saw、Spikes、Glow、Star、Backdrop 全部 RuntimeArt 代码生成。
- 音频 0 个文件，ProceduralAudio 合成 9 个 SFX + 1 段 8 秒环境音。
- UI 全代码生成纯色 Image + TMP，无 9-slice / 图标 / 按键提示；字体 ZCOOL 单字重（非像素），运行时 TMP_FontAsset.CreateFontAsset 建图集。
- 无 ParticleSystem、无 .anim/.controller、无 Prefab、URP Volume 未启用。

推荐方向：维持 1-bit + MonoTint 调色（与现有 MonoTint.shader 和 RoomPalette 一致），缺口用 CC0 1-bit 包闭环。
关键待补：完整角色帧、独立敌人动画、正式瓦片组（含边缘/单向平台）、真实 SFX 与音乐、粒子 VFX、9-slice UI、CJK 像素字体。

- 首选 Super Grotto Escape（CC0 免费，16x16 无偏移，洞穴/遗迹瓦片 + 多层视差 + 主角 + 9 敌 + VFX + chiptune）：https://ansimuz.itch.io/super-grotto-escape-pack
- 冷调路线 Gothicvania Cold Corridors（免费）+ Cemetery（CC0，主角 6 动画含死亡、3 敌、3 无缝背景）
- 付费最整体 Szadi Fantasy Platformer All Sets（6 张图 + 昼夜视差）
- 单件补强：Hero Knight（100 帧，含墙滑/抓边/滑行尘土）；Super Pixel Effects Gigapack（91 种免费特效）

关键技术结论（换皮时必守）：
- 三套均为 16x16 → PixelsPerUnit 仍是 16，RoomCatalog 里所有世界坐标与 PlatformSpec 尺寸无需改。
- 视差背景必须挂在 RotatingStage 之外 —— RoomBuilder 现有 Backdrop 已是 sibling，可直接复用。
- 有重力暗示的装饰（火把、草皮、垂枝）不能进旋转舞台，会随 90° 旋转露馅。
- 换 16-bit 后 MonoTint 调色方案要退役，相位区分改为去饱和/剪影 shader（PhaseSurface 目前只改 color）。
- Oak Woods（brullov，24x24）虽美但与现有 16 PPU 冲突，会让 4 间房坐标全偏，暂不推荐。

## 朝向 bug 修复（用户反馈）
素材朝向实测结论（用「脸/眼睛在身体中心的哪一侧」量化判断，别靠肉眼猜）：
- `Character.png`（主角兔）**原生朝右**。
- `GhostWalk.png`（幽灵怪）**原生朝左** —— 品红眼睛像素质心 x=12.8，身体中心 16.5。
- `Kenney1Bit/Ghost.png`（小精灵）**原生朝左**。

原 bug 与修复：
- 主角：`SpriteAnimator2D.SetFacingLeft` 写的是 `flipX = !left`，等于「往右走才镜像」，方向反了 → 改成 `flipX = left`；`SetFacing(dir)` 同步改成 `flipX = dir < 0f`。
- 怪物：`GhostPatrolView` 原本没有任何翻转逻辑 → 新增 `UpdateFacing()`，按逐帧世界 X 位移的符号决定 `flipX`（幽灵原生朝左，所以 `flipX = delta > 0f`），放在提前 return 之前保证始终执行。用世界坐标而非 localPosition，旋转舞台转 90° 时朝向跟随屏幕方向。
- 小精灵：原来是 `flipX = _target.localScale.x < 0f`，而主角 localScale 恒为 1，等于永不翻 → 改为读 `PlayerController.Facing`（新增公开属性，1 朝右 / -1 朝左），`flipX = Facing > 0f`。

排查手法（可复用）：把同一精灵摆 flipX=false / true 两份并排渲染，用「已知朝向的素材」当参照去判定未知素材，避免猜错；`execute_code` 里渲染要先把 PixelPerfectCamera.enabled 关掉，否则它每帧覆盖 orthographicSize。
